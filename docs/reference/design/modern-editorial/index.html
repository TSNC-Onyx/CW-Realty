Modern Editorial

Magazine-style and airy. Warm off-white pages, large elegant headlines, big photos; gold is saved for thin rules and icons on black bands. The binding rules are in docs/constitution/02-style-ui-ux.md §11; where these screens and §11 differ, §11 wins.

Known differences from §11

  • Hero lead text is 19px desktop / 17px mobile on the screens; §11.2 sets 20px / 18px.
  • The name field shows "Looks good" without a prior error; §11.11 allows it only after an error is fixed.
  • The desktop header does not draw the current-page underline or the desktop "Chat with us" launcher described in §11.9 and §11.13.
  • Bracketed text ([PRICE], [PHONE], [Status], [Role], etc.) is placeholder content, not a design choice.

Full size: components-messages-content.html · image: components-messages-content.png

  1. Colors (§11.1). Gold only on black: it scores 10.4:1 contrast there but only 1.7:1 on the off-white page, which fails accessibility.
  2. Type (§11.2). Fraunces headings, Manrope body, two font families only; nothing below 14px.
  3. Buttons (§11.5). Every button shows six states: default, hover, keyboard focus (blue ring), pressed, disabled and loading ("Sending…").
  4. Messages (§11.12). Success, error, warning and info each use an icon plus words, never color alone; errors say what to do next and keep what the visitor typed.
  5. Form (§11.11). Labels above fields, 52px tall fields, errors appear under the field when the visitor leaves it. Note: the green "Looks good" on the name field is shown for illustration; §11.11 only allows it after an error is fixed.
  6. Page formatting (§11.4, §11.12). Breadcrumbs, H1 56px, lead, article H2 32px, short paragraphs, bullet list, dark callout, descriptive link; 680px max width.
  7. Empty state, chat, cookie banner (§11.13). Empty state explains what belongs there and the next step; chat is labeled "AI · NOT A PERSON", cites its source, always offers a person; cookie Accept and Reject are equal.
  8. Mobile screens (§11.9, §11.12). Menu open (current page marked with a gold bar), form with errors (summary at top links to the field), and the success page after sending.
