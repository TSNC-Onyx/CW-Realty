# Admin/Control System Constitution

> Section 4 of 4. Binding for all work in this repo. Supplied by the owner on 2026-09-25; do not edit without owner approval.

## 1. Editing Experience (NN/g, WCAG 2.2)

- Plain labels, large inputs, one fixed Save button per screen
- Dashboard shows every editable area as a labeled card
- Works fully on mobile
- Toast confirms each save; errors stay until dismissed and name the field to fix
- Toasts announced to screen readers (WCAG 4.1.3)
- Warn before leaving with unsaved changes
- Preview before publish; undo instead of repeated confirm pop ups

## 2. Featured Properties

- Add, edit, remove, reorder, and mark as draft or live
- Required: photos, price, address, status, description
- Alt text required on every photo; images auto resized
- Mark listings as sold or pending without deleting them

## 3. CWR Team

- Add, edit, remove, and reorder the grid by drag or up/down buttons
- Each member gets a profile page: photo, title, bio, contact
- Hiding a member keeps their page for later reuse
- Member order and visibility update the live grid instantly

## 4. Contact & Footer

- Edit phone, email, and contact names once; updates everywhere
- Phone and email formats checked before saving
- Phone numbers become tap to call links on mobile

## 5. Notifications & Inbox

- Choose who receives Contact Us and chat alerts
- Send a test alert to confirm delivery
- Inbox filters: new, assigned, replied, closed
- Assign messages and add internal notes
- Reply from the inbox; each thread shows its full history
- Unread count shown on the dashboard

## 6. Chatbot Policy

- Upload or edit the policy file with a live test chat
- Version history with one click restore
- Changes publish only after a test run passes
- Only owners can edit the policy file

## 7. Access & Safety

- Roles: owner, manager, staff; each sees only what it needs
- Multi factor login; every change logged with who and when
- Sessions time out after inactivity
- Deleted items go to trash for 30 days before permanent removal
